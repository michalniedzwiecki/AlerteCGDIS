## Alertes CGDIS 1.8

### Nouveautés
- **Correction : l'application n'est plus bloquée par Google Play Protect** (« Harmful app blocked », apparu avec la 1.7). L'application n'installe plus elle-même les mises à jour.
- La recherche de mise à jour reste automatique : à l'ouverture, un bandeau vert « Version X.Y disponible » s'affiche quand une nouvelle version existe. **Télécharger** ouvre le téléchargement dans le navigateur ; ouvrir ensuite le fichier téléchargé et confirmer l'installation.
- Paramètres › Mises à jour : rechercher une nouvelle version à la demande ou ouvrir la page de téléchargement.

### Installation
1. Télécharger `AlerteSMS-1.8.apk` ci-dessous sur le téléphone.
2. L'ouvrir et autoriser l'installation d'applications de source inconnue si Android le demande.
3. Au premier lancement, accorder les permissions de la checklist.

**Mise à jour depuis la 1.1 à 1.7 :** installer par-dessus la version existante, sans désinstaller : les paramètres, l'historique et les modèles de traduction sont conservés.

> Si Play Protect affiche encore un avertissement, choisir « Envoyer l'application pour analyse » puis « Installer quand même ».
> Cet APK est prévu pour les téléphones (ARM) ; il ne s'installe pas sur un émulateur x86.
